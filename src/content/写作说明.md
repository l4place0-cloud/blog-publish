# 博客写作 Vault

这个目录可以直接作为 Obsidian Vault 打开。只有以下三个目录中的 Markdown / MDX 会发布到博客：

- `articles/`：完整文章
- `projects/`：项目案例
- `space/`：想法、动态、链接、图片、书影音和代码片段

`Templates/` 是 Obsidian 模板目录，`attachments/` 用于保存粘贴或拖入的图片；它们不会被博客当成内容发布。

## 新建内容

1. 先在目标栏目中新建文件，文件名使用稳定的英文 slug，例如 `my-first-post.md`。
2. 打开命令面板，执行“模板：插入模板”。
3. 选择对应的文章、项目或空间模板。
4. 修改 Front Matter 并完成正文。
5. 写作期间保持 `draft: true`，准备发布时改为 `draft: false`。

## 图片

Obsidian 会把粘贴或拖入的附件放入 `attachments/`。在 Front Matter 中，从文章、项目或空间目录引用附件时使用：

```yaml
cover: ../attachments/cover.png
```

空间图片类型使用：

```yaml
images:
  - ../attachments/photo.png
```

正文中的图片建议使用标准 Markdown 相对链接：

```md
![图片说明](../attachments/photo.png)
```

## 引用关系

内容关系使用目标文件名的 slug，不使用 Obsidian 双链语法：

```yaml
projects: [project-slug]
sourceSpace: [space-note-slug]
project: project-slug
relatedArticle: article-slug
```

构建会校验这些引用，写错或引用不存在时会直接报错。
