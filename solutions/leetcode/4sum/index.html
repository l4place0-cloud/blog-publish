思路

🔗 最初的思路

2sum问题 是 建立 数组中每个数对Target的差 到 对idx 的映射，本质上是逆向思维的体现，将问题从 正向找和 到 逆向记差 的转变。

从 2sum问题 出发，拓展到 3sum问题 问题的关键在于继续沿用逆向思维 -> 假设已经找到了某个 2sum，现在我们只需要在剩下的数组中找到一个值 v 满足 2sum + v == target，也就是建立 target - v 到 对应idx 的映射 -> 然后问题转化为 2sum问题。

从 3sum问题触发，拓展到 4sum问题 同 3sum问题，一样的逆向思维，先建立 第四个数值 的Target差映射，然后是 第三个数值，以此类推。

❌ 你提出的“建立映射”思路在 2Sum 中是非常完美的（用空间换时间）。但在 3Sum 和 4Sum 中，如果继续使用 unordered_map 来存储差值，会遇到两个致命问题：

  1. 去重困难（最麻烦的点）：题目要求返回“不重复的四元组”。哈希表丢失了顺序信息，[-1, 0, 1, 2] 和 [0, -1, 2, 1] 在哈希表中很难判断为同一个解，除非你对结果再进行一次繁琐的排序去重。

  2. Key 冲突：um_v2 中如果有多个组合都能凑出同一个差值，map 会覆盖掉前面的索引，导致你漏掉解。

❗ 正确的“降维打击”策略

对于 K-Sum (K > 2) 问题，业界的标准解法是将问题层层降维，但不用哈希表，而是用 排序 + 双指针。

4Sum：固定 i，问题变为在剩余数组中找 3Sum。

3Sum：固定 j，问题变为在剩余数组中找 2Sum。

2Sum：在有序数组中，用双指针 L 和 R 快速找到 target。

这依然是你说的“逆向思维”（Target - nums[i]），但用双指针代替哈希表来解决去重和覆盖问题。

⭐ 你最初的代码试图通过缓存中间结果（Map）来加速，这在很多算法题中是高阶技巧（如动态规划）。但在 K-Sum 问题中，由于去重是核心难点，排序+双指针才是这一类问题的“通解”。

  1. 核心步骤：排序

排序是为了方便去重，以及使用双指针

  1. 第一层循环：固定第一个数 a (索引 i)

去重：如果我们已经处理过这个数作为第一个数，跳过

剪枝 1：当前最小的四个数之和都大于 target，后面不可能有解了，直接结束

注意：使用 long long 防止溢出，题目提示 target 和 nums[i] 较大

剪枝 2：当前数加上最大的三个数都小于 target，说明 nums[i] 太小了，这一轮没戏，看下一个 i

去重：对于当前的 i，如果 nums[j] 重复了，跳过

#include <vector>
#include <algorithm>

using namespace std;

class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> ans;
        int n = nums.size();
        if (n < 4) return ans;

        // 1. 核心步骤：排序
        // 排序是为了方便去重，以及使用双指针
        sort(nums.begin(), nums.end());

        // 2. 第一层循环：固定第一个数 a (索引 i)
        for (int i = 0; i < n - 3; ++i) {
            // 去重：如果我们已经处理过这个数作为第一个数，跳过
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            // 剪枝 1：当前最小的四个数之和都大于 target，后面不可能有解了，直接结束
            // 注意：使用 long long 防止溢出，题目提示 target 和 nums[i] 较大
            if ((long long)nums[i] + nums[i + 1] + nums[i + 2] + nums[i + 3] > target) break;

            // 剪枝 2：当前数加上最大的三个数都小于 target，说明 nums[i] 太小了，这一轮没戏，看下一个 i
            if ((long long)nums[i] + nums[n - 3] + nums[n - 2] + nums[n - 1] < target) continue;

            // 3. 第二层循环：固定第二个数 b (索引 j)
            for (int j = i + 1; j < n - 2; ++j) {
                // 去重：对于当前的 i，如果 nums[j] 重复了，跳过
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;

                // 二级剪枝：同理
                if ((long long)nums[i] + nums[j] + nums[j + 1] + nums[j + 2] > target) break;
                if ((long long)nums[i] + nums[j] + nums[n - 2] + nums[n - 1] < target) continue;

                // 4. 双指针：寻找 c (left) 和 d (right) —— 本质就是解决 2Sum
                int left = j + 1;
                int right = n - 1;
                while (left < right) {
                    long long sum = (long long)nums[i] + nums[j] + nums[left] + nums[right];

                    if (sum == target) {
                        ans.push_back({nums[i], nums[j], nums[left], nums[right]});
                        
                        // 找到答案后，继续收缩指针，同时跳过重复元素（去重关键）
                        while (left < right && nums[left] == nums[left + 1]) left++;
                        while (left < right && nums[right] == nums[right - 1]) right--;
                        
                        left++;
                        right--;
                    } else if (sum < target) {
                        left++; // 和太小，左指针右移
                    } else {
                        right--; // 和太大，右指针左移
                    }
                }
            }
        }
        return ans;
    }
};
